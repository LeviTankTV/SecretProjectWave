# WAVEBORN — спека «насыщенности» (20 вопросов, ответы игрока)

Референс игрока: florr-скриншот («Garden, Wave 508») — ряд карточек с рамкой
в цвете редкости, иконкой вида, бейджем ×N; редкие карточки перекрывают частые.

## ГЛАВНОЕ УТОЧНЕНИЕ
Карточки — это **МОБЫ ВОЛНЫ** (ростер), не петали!
И: **истинные тиры (Dot..Origin) у МОБОВ в игре быть не должны** — потолок
редкости мобов = Chaos (7). Истинные редкости остаются только у ПЕТАЛЕЙ
(крафт Dot..Origin). Из этого следует правка Волн 2.0 (см. №14).

## Ответы

### Карточки мобов волны (ростер)
1. Карточки мобов волны в стиле florr: рамка = цвет редкости, силуэт моба,
   градиентная заливка редкости, ×N. (не петали — мобы!)
2. Слоение: **каскад с перекрытием** — редкие поверх частых.
3. Заливка карточки: **градиент редкости** (у высоких насыщеннее).
4. Счётчик: **×N белым жирным в углу** (как на скрине) — сколько таких мобов
   осталось в волне.
5. Расположение: **под табло волны** (сверху по центру).
6. Иконка: **тёмный силуэт моба** на градиенте редкости.
7. Порядок: **частые слева, редкие справа** — редкость растёт слева направо,
   редкие перекрывают правый край.

### Мобы — визуальная насыщенность
8. Ауры редкости: **усилить** (Fractal+ — пульсирующее двойное кольцо).
9. Смерть моба: **взрыв осколков** (6-10 частиц в цвете редкости + вспышка).
10. Попадания: **искры + лёгкая тряска камеры** (порт идеи mob_hit_fx +
    camera_fx родителя).
11. Подвиды: **эффекты каждому** — Gold: золотые искры; Ring: вращающееся
    кольцо; Star: звёздные блики; Crescent: тень-серп.

### Арена и атмосфера
12. Фон арены: **биомный градиент выбранной зоны** (Point зелёный … Chaos
    тёмный) — бой идёт в разных зонах, палитра от зоны.
13. Пол: **тонкая гекс-сетка** (WAVEBORN-мотив) + виньетка краёв.
14. Декор: **пропсы биома** (кристаллы/рострики/обломки; порт идеи
    zone_props родителя), за мобами, не мешают бою.
15. Атмосфера **нарастает с волнами**: с Fractal-волн — частицы в воздухе,
    боссы высоких тиров — затемнение краёв + красное свечение.

### Высокие редкости и фидбек
16. **True-тиры мобов (Dot..Origin) убрать из игры**: потолок мобов — Chaos.
    (Следствия: waveRarityFor кап 7; босс-лестница после Chaos(30) — Chaos-
    боссы с растущим HP/элитой; bud/marble/lancer/javelin/darter/spikelance —
    редкие спавны в родных зонах (Point/Line) на обычных редкостях.)
17. Редкий дроп: **крупный тост-алерт** по центру (Fractal+ петали, золотые
    мобы): иконка + имя + рамка редкости.
18. Лобби-превью: петали игроков — **теми же карточками** (единый язык).
19. Звук дропа: **джингл растёт с редкостью** (клик → арпеджио → фанфары).
20. Редкости петалей: палитра родителя остаётся.

## Порядок реализации (предлагаемый)
- Б1: карточки мобов волны (ростер) — флагман фичи (№1-7).
- Б2: сервер: кап мобов на Chaos (№16) + спавн древних стражей в родных зонах.
- Б3: эффекты мобов: ауры/смерть-осколки/искры+тряска/подвиды (№8-11).
- Б4: арена: биомный градиент + гекс-сетка + пропсы + атмосфера (№12-15).
- Б5: алерты редкого дропа + джинглы + карточки в лобби (№17-19).
