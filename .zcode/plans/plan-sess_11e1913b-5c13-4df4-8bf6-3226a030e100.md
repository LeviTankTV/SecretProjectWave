## Найденные баги (ревизия сквадов/лобби)
1. **Призрачные пати** — `cleanupStaleLobbies` нигде не вызывается; при закрытии вкладки без «Leave» лобби живёт вечно и висит в публичном списке (главная жалоба: «все вышли — а пати не удаляется»).
2. **Гонка данных** — `genLobbyCode` (lobby.go:37) читает `lobbies` без `lobbyMu` → возможен краш «concurrent map read and map write».
3. **Мёртвая комната** — при удалении лобби `Room.close()` не закрывает WS подключённых игроков: они висят в замершей игре.
4. **Ник залипает после обрыва** — при реконнекте (обрыв сети/сон ноутбука) до 60с сервер отвечает «This nickname is already in use!» и клиент вылетает в меню.
5. **Повторный Start** во время отсчёта сбрасывает таймер и мобов (`beginWaves` не защищён от `wavePending`).
6. **Утечка ника** — `usedNiks map[string]bool`: отложенный RemoveClient старого соединения освобождает ник, уже занятый новым игроком.

## Фиксы
### server/lobby.go
- `genLobbyCode` берёт `lobbyMu` (фикс гонки).
- Трекинг активности: `memberSeen[nick]` обновляется в `lobbyBase` (все lobby-API) и при create/join.
- **Reaper** `reapIdleLobbies()` + горутина `lobbyReaperLoop()` (тик 30с, запуск из main.go): участник без активности И без живого WS в комнате выкидывается из пати (5 мин; 15 мин если матч уже идёт — запас на реконнект); пустое лобби удаляется с хост-переносом и `Room.close()`; лобби старше 24ч — целиком. Старый `cleanupStaleLobbies` удаляется.

### server/room.go + net.go
- `usedNiks` → `map[string]int` (счётчик): AddClient ++, RemoveClient/ReturnToMenu −−, delete при 0.
- `Client.lastRecv` (atomic, обновляется в readPump) + `takeOverStaleSession`: если ник занят соединением, молчащим > 15с (обрыв) — старая сущность снимается с сохранением профиля, коннект закрывается, новый игрок входит бесшовно; живое соединение не трогаем (две вкладки = last-wins без ping-pong войны).
- Единые хелперы `detachPlayerLocked`/`persistDetach` (снимок+удаление под локом, сейв вне лока) — RemoveClient/ReturnToMenu/takeover.
- `Room.close()`: останавливает gameLoop/autosave И закрывает все клиентские коннекты (игроки корректно выкинутся в меню).
- `Room.hasClientNamed()` для reaper.

### server/waves.go
- `beginWaves`: ранний выход при `wavePending || waveRunning` — повторный Start не сбрасывает отсчёт.

### Клиент (client/js/lobby.js)
- Авто-открытие экрана пати при загрузке, если в localStorage есть код лобби (F5 во время матча → сразу «Match running» → авто-вход в арену).
- Уведомление «Party disbanded», когда пати распалось само (не после своего Leave).
