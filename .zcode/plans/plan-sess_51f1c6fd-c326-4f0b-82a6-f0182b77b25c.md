# План: командная волновая игра — дроп на всех, team-профили, wave bar с ростером мобов, баланс из SecretProject

## A. Сервер (waves.go / room.go / mob.go / minion.go)

**A1. Мобы не спавнятся на игроках.**
`spawnWaveMobAt`: точка спавна отклоняется, если ближе 300px к любому живому игроку (до 8 попыток, иначе дальняя случайная точка арены; клэмп в круг остаётся).

**A2. Дроп с моба — для всей команды.**
`awardMobKill`: в волновом режиме для КАЖДОГО игрока комнаты создаётся своя персональная копия дропа (`OwnerID` = ник каждого): один моб → до 4 одинаковых личных дропов. Логика выбора дропа (mobDropKind/rare/rarity) не меняется.

**A3. Wave bar — серверная логика завершения волны.**
Состояние волны рассылается в `StateMsg` (phase, fraction1, fraction2).
- Фаза «spawn» (слой 1): прогресс = заспавнено/всего.
- Всё заспавнено и живых ≤5 → волна завершена сразу; если >5 → фаза «hold» (слой 2): таймер `waveHoldDur` (20с) течёт поверх первого слоя; дошёл до конца — **волна принудительно завершается**, даже если мобов >5.
- Живых стало ≤5 в любой момент — волна завершена немедленно.
- `startWave` чистит выживших; передышка между волнами 3с.

**A4. Ростер живых мобов (под wave bar).**
Сервер в `StateMsg` отдаёт сводку: для каждой пары (тип моба, редкость) — сколько живых. Клиент рисует под полосой ряд чипов: иконка/цвет моба + название + цвет редкости + ×количество (напр. «Dot ● 3, Square ◆ 2»), сортировка по редкости/типу, обновление в реальном времени.

**A5. Портировать из SecretProject (новый баланс):**
- `petalVsMobMult` (tier-gate урона, mob.go:36-45 + beamorb.go);
- `mobStatsForRarity` / `summonMobStats` / `summonDeepDebuff` + `summonSpec` (minion.go);
- `voidDashStep = 6.0` (анти-туннель void-рывка);
- вне-боевой реген мобов (20с / 1.5%);
- константы: saturn 140/30 и DPS 8, spike 20/0.5с, bulwark 0.8, shield 10/5, петаль saturn 22/7.
Не портирую (не применимо к круговой арене): per-corner радиусы стен, тач-контролы.

## B. Клиент

**B1. Team-профили слева:** карточки других членов команды (круг в цвете игрока, ник, полоса HP), обновление каждый тик из `state.players`.
**B2. Wave HUD сверху:** крупный «Wave N» (+★ и название спец-волны), двухслойная полоса (спавн / hold), под ней — ростер живых мобов из A4.
**B3. Тултипы/статистика:** обновить `PETAL_DB` в main.js описаниями нового баланса из оригинала (синхронно с A5).

## Проверка
Тесты Go (новые условия завершения волны, no-spawn радиус, персональный дроп каждому), сборка, живая проверка: мобы не спавнятся на игроках, дроп подбирают все, полосы/ростер ведут себя по фазам (включая принудительный запуск по hold-таймеру), team-профили обновляются, тултипы нового баланса.
