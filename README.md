# SecretProjectWave — кооперативный волновой выживач

Пет-проект на базе SecretProject (дипломная работа). Браузерная 2D игра:
игроки с орбитальными петалами отбивают бесконечные волны мобов вдвоём-восьмером,
создав лобби в главном меню (публичное — в списке, приватное — по 6-значному коду).

## Технологии

- **Клиент** — JavaScript + PixiJS (без бандлера)
- **Сервер** — Go (gorilla/websocket, mongo-driver)
- **БД** — MongoDB `secretprojectwave` (коллекция `users`: ник, прогресс, инвентарь, хотбары, `best_wave`)
- **Связь** — WebSocket `/ws` (20 тиков/сек) + REST для меню/лобби. Философия прежняя: «сервер считает, клиент рисует».

## Игровые системы

- **8 редкостей** (Point → Chaos) с серверным скейлингом HP/урона/размера.
- **Петалы** на орбите, 2 хотбара + инвентарь, крафт (+1 редкость) и абсорб (за XP).
  Новым игрокам выдаётся 5 Oval (Point).
- **Волны** (`server/waves.go`): мобы спавнятся пачками до конца волны; редкости
  растут с номером волны (floor = N/6, ceil = N/3+1). После зачистки — 10 сек передышки.
- **Спец-волны**: каждая 5-я — Swarm / Tanks / Hunters (ротация), каждая 10-я —
  боссовая волна с Fractal-мобом.
- **Прогрессия**: XP за мобов → уровни → кап орбиты петалов; рекорд «лучшая волна»
  сохраняется в профиль.

## Запуск

Самый простой способ — двойной клик по **`server\start.bat`**: он сам убьёт процессы
на игровых портах, проверит MongoDB (попробует поднять службу), пересоберёт сервер
из исходников и будет автоматически перезапускать его при падении (watchdog).
Остановка — закрыть окно или Ctrl+C.

Вручную:

1. MongoDB на `127.0.0.1:27017`.
2. `cd server && go build -o server.exe .`
3. Запускать exe **из папки `server/`** (клиент раздаётся из `../client`):
   `cd server && .\server.exe` (HTTPS :8090, HTTP :8091; `PORT`/`HTTP_PORT` — переопределить).
4. Открыть `http://localhost:8091` (без предупреждений сертификата) или
   `https://localhost:8090`, зарегистрироваться, создать лобби, Press Play, хост жмёт Start.

## Архитектура лобби

- `POST /api/lobby-create {token, public}` / `lobby-join {token, code}` /
  `lobby-list` / `lobby-info` / `lobby-leave` / `lobby-start` (только хост).
- Каждое лобби — отдельная изолированная `Room` (`newWaveRoom`): своя арена (зона 0),
  свои мобы/дропы, порталы отключены. Пустое лобби удаляется, горутины останавливаются.
- WS-hello несёт код лобби; без лобби подключение отклоняется.
