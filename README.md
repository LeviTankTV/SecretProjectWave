# SecretProjectWave 2.0 — кооперативный волновой выживач

Пет-проект на базе SecretProject (дипломная работа). Браузерная 2D игра:
игроки с орбитальными петалами отбивают бесконечные волны мобов вдвоём-восьмером,
создав лобби в главном меню (публичное — в списке, приватное — по 6-значному коду).

**Адаптация 2.0** — проект синхронизирован с родительским SecretProject
(модульный порт подсистем): 16 редкостей, ~48 мобов, 47 петалей с грейдами,
XP-экономика родителя, волны до Origin, генеративный звук.

## Технологии

- **Клиент** — JavaScript + PixiJS (без бандлера)
- **Сервер** — Go (gorilla/websocket, mongo-driver), `internal/worlddata` + `rarity` (единые с родителем пакеты данных)
- **БД** — MongoDB `secretprojectwave` (коллекция `users`: ник, прогресс, инвентарь, хотбары, `best_wave`, `achievements`)
- **Связь** — WebSocket `/ws` (20 тиков/сек) + REST для меню/лобби. Философия: «сервер считает, клиент рисует».
- **Репозиторий** — https://github.com/LeviTankTV/SecretProjectWave

## Игровые системы (2.0)

- **16 редкостей**: зонная лестница Point→Chaos (0..7) + истинная Dot→Origin (8..15).
  Единый реестр `server/rarity` генерирует `client/js/rarities.js` (go generate).
- **Волны 2.0** (`server/waves.go`): редкости растут как floor=N/4, ceil=N/2+1 —
  Dot в пуле с ~16-й волны, Origin в потолке с 28-й. Спец-волны каждые 5-е
  (ротация Swarm/Tanks/Hunters), **босс-волны каждые 10-е** — лестница
  Hexagon(10)→Fractal→Chaos→Dot(40)→…→Origin(110+), **элитные волны каждые 25-е**
  (все мобы — подвиды). Арена растёт +25 радиуса за 5 волн (1300→2200).
- **Мобы**: ~48 видов из `internal/worlddata` (как у родителя): trinity
  (тройной организм), fragtank (башня), origin-стражи (bud/marble/lancer/
  javelin/darter/spikelance), nova/mirror, arrowhead/shardwing/zigzag/quarry/
  frame/kite + **подвиды** gold/ring/star/crescent. Chaos-способности:
  притяжение Black Hole, аура Saturn, телепорт Void, инверсия Entropy.
- **Петали**: 47 видов с per-kind перезарядкой (0.6–1.6×) и **грейдами Pot**
  (UNIQUE→PARAGON, 100–200%): один грейд множит HP/DMG и пассивки, стеки
  по (вид, редкость, грейд), катушка крафта тратит худший грейд.
- **Крафт**: 5→1 редкость+1, шансы из реестра (вкл. Chaos→Dot 4%), провенанс
  (CraftedBy/CraftedAt), крафтовый пол урона Hexagon+.
- **Абсорб**: цена по номиналу каталога (анти-эксплойт Pot), потолок
  10 «убийств» редкости, штраф tierGap.
- **Прогрессия**: кривая 45×1.11^L (мягкий кап 60), детерминированный XP за
  киллы, анти-фарм tierGap (×0.65/тир разрыва). Миграция профилей prog_ver 2
  (xp_total — источник истины).
- **Дропы**: 16-строчная таблица редкостей, командные персональные дропы
  каждому живому игроку, боссы истинной лестницы дают бонусную пачку.
- **Звук**: генеративный WebAudio (`client/js/audio.js`) — ноль ассетов,
  SFX + процедурная музыка, микшер в Settings.
- **Достижения волн**: милстоуны 10/25/50/100 (чипы в меню).

## Запуск

Самый простой способ — двойной клик по **`server\start.bat`**: он сам убьёт процессы
на игровых портах, проверит MongoDB (попробует поднять службу), пересоберёт сервер
из исходников и будет автоматически перезапускать его при падении (watchdog).

Вручную:

1. MongoDB на `127.0.0.1:27017`.
2. `cd server && go build -o server.exe .`
3. Запускать exe **из папки `server/`**: `cd server && .\server.exe`
   (HTTPS :8090, HTTP :8091; `PORT`/`HTTP_PORT` — переопределить).
4. Открыть `http://localhost:8091`, зарегистрироваться, создать лобби, Press Play, хост жмёт Start.

Тесты: `cd server && go test ./...` (включая headless-прогон волн
`waves2_e2e_test.go` — лестница редкостей, босс-волны, ротация спец-волн).

## Архитектура лобби

- `POST /api/lobby-create {token, public}` / `lobby-join {token, code}` /
  `lobby-list` / `lobby-info` / `lobby-leave` / `lobby-start` (только хост).
- Каждое лобби — отдельная изолированная `Room` (`newWaveRoom`): своя арена,
  свои мобы/дропы, порталы отключены. Пустое лобби удаляется, горутины останавливаются.
- WS-hello несёт код лобби; без лобби подключение отклоняется.

## Ченджлог адаптации 2.0

Этапы (коммиты в git): 0 базлайн → 1 реестр 16 редкостей → 2 worlddata +
варианты мобов + ИИ-способности → 3 грейды Pot + перезарядка per-kind →
4–5 XP-кривая родителя + абсорб с капами + миграция профилей → 6 Волны 2.0
(лестница до Origin, босс-волны; попутно исправлен старый баг: босс-волны
шли без босса) → 7 клиент: витрина дизайнов 24–77 + легаси 1–111, формы
tank/zigzag/quarry/nexus, карточки с грейдами → 8 статистика забега в
gameover + грейд-ревил крафта → 9 звук + достижения волн.

## Роадмап (не вошло в 2.0)

- Магазин и косметика (осколки из XP-оверфлоу, скины/шляпы/трейлы/питомцы).
- Полный i18n (русский словарь Wave-UI).
- Абилки боссов (dash/volley/ring/teleport из конфига тиров родителя) и
  Nexus как босс высоких волн.
- Конфиг-оверрайды баланса из config.json (живая правка волн/петалей).
- Плейтест-калибровка кривой волн (TTK боссов, экономика осколков).
